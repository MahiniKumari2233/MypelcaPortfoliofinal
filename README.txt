MAHINI KUMARI — INTERACTIVE PORTFOLIO

How to use:
1. Keep the folder structure unchanged.
2. Open index.html in a browser.
3. Use the navigation to open each section as a separate HTML page.
4. Certificate images in the Certifications page are clickable and open in a larger modal.
5. Achievement certificate buttons open the Adobe and IIT Bombay certificates.

Files:
- index.html
- skills.html
- projects.html
- achievements.html
- certifications.html
- internship.html
- training.html
- education.html
- style.css
- script.js
- assets/img/profile-square.jpg
- assets/certificates/*

The content is based on the supplied CV and uploaded certificates. The Adobe certificate was reconstructed for display from the user-provided MHT's certificate background plus its embedded certificate details because the saved webpage background separates the text layer.
